# Render robot appearance from state with the shared Franka renderer

Robot-only RGB for training supervision is generated by a state renderer from synchronized qpos, per-source URDF, and camera calibration — the direction ADR-0013 set and ADR-0015 deferred. Both of ADR-0015's reasons for deferral have dissolved under the TiPToP integration plan ([integration plan](../tiptop-gwm-integration-plan.md) D8):

- Development evaluation moves to droid-sim and MolmoSpaces (ADR-0018), where inference-time candidates are rendered from proposed joint trajectories, not cut from observed segmentation. Mask-derived training appearance would now itself create the train-versus-inference condition mismatch that ADR-0015 tried to avoid.
- The renderer is built for inference scoring regardless, so there is no front-loaded engineering to avoid.

One shared renderer (`FrankaRobotRenderer`: SAPIEN, batched qpos → robot-only RGB, camera intrinsics/extrinsics/resolution injected at call time, per-source URDF) serves all training-data generation and all inference scoring. Train/inference render homology is a hard requirement, not a preference. Verified embodiment facts (2026-08-06): MolmoBot-Data, the MolmoSpaces rig, and the TiPToP hardware rig all use an FR3 with the Robotiq 2F-85; the real DROID rigs behind MolmoAct2-DROID use the Panda with the same gripper. Gripper state arrives as two driver-joint values (MolmoBot) or a continuous gripper position (DROID), so the renderer reconstructs the full 2F-85 linkage through its mimic-joint model in both cases.

## Consequences

ADR-0015 is superseded; the mask-derived path survives only inside the optional VRS ablation arm (ADR-0016), where its provenance is recorded as before. ADR-0013's semantics return: rendering happens in a robot-only scene against black, and observed masks, predicted masks, depth, and scene geometry never clip the rendered robot. Per-source pre-flight verification — URDF re-projection pixel-aligned against the source RGB on sample episodes — is a hard gate before any large-scale rendering. Robot-only RGB remains exempt from photometric augmentation, and each source still fixes one recorded appearance provenance per run.
